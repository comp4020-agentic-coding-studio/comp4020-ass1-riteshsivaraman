# Assignment 1 — reflection

## What was the breakthrough that moved the work forward?

I realised that when I stopped writing code and started writing for the thing that
writes code, this moves where my mistakes start off and live.

Usually, when I write a function badly, the bug sits in a line and eventually
gets found out. When I write a *rule* badly, however, the agent follows it
faithfully, everywhere, immediately. The result is consistent, internally
coherent bugs that are uniformly wrong. Because nothing looks broken and
nothing disobeyed anything, that failure is far harder to spot than a bad line
of code, and it only became apparent when I stopped asking for the page to be
fixed and started asking why it had been built that way.

The uncomfortable part was knowing the harness was mine, and that its blind spots were
my blind spots, written down and automated. The green checks I had been
prioritising were never a measure of how good the work was, but evidence that it
matched what I had thought to measure — even if that was the wrong thing.

Simply patching each symptom as it appeared seemed like the easy way. However, changing the
process based on the bugs was the better decision I ended up taking.

## What did this work change about who I want to be as a software developer?

I want to be suspicious of green ticks, and not blindly trust them.

This doesn't mean to be dismissive of checks. Sometimes they caught real things I could never have seen by
eye. However, a passing suite only meant the work satisfied whatever I
remembered to ask of it. The habit I want to build is asking what I have pointed nothing at,
because that is the most fragile part, where ambiguities lead to poor and
undesirable outcomes.

If I can't trust green, the fallback isn't another test — it's looking. So the
practice I want is an unglamorous one: open the real thing, at both sizes,
repeatedly, and say what I see even when I can't yet say why. The vaguest,
least technical thing I said all assignment was "this feels dead", and it was
worth more than any check I owned.
